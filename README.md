## **// Description**

**Low Ready Project** is heavily inspired in **Arena Breakout Infinite** and **Ready or Not** style of gameplay. **Inspired**, not 100% copied.
Movement speeds are now slower. Sprint head bobbing is reduced. Camera lean mechanic is fully implemented.
Values of speed, head bobbing and lean keybinds are all customizable.

## **// Installation Instructions**

- Install **SuperBLT** separately (https://modworkshop.net/mod/58342).
- Extract the mod **.zip** into **PAYDAY 2\mods**.
- Confirm that the path **PAYDAY 2\mods\LowReadyProject\mod.txt** is correct.
- Open PAYDAY 2 in **local single-player** and configure Low Ready Project through the SuperBLT mod options menu.

## **// Main Features**

- Adjustable walk, sprint and crouch speed (10–100%; 60% defaults).
- Adjustable sprint head bob (10–100%; 50% default).
- Smooth left and right camera lean, with remappable keybinds (defaults Q/E) and the option to use toggle or hold modes.

## **// Compatibility**

Mod only tested in **local single-player** missions and **no other mods** installed. Any other mod that changes movement speed in any way **will conflict** and cause issues with **Low Ready Project**. Mod is **client-side only**.
